# Front v10.7.31 — Um botão para iniciar e executar o ciclo Live

**Branch:** `feature/v10.7.31-live-one-click-cycle`
**Base:** frontend `main` commit `1d1be17b`

## Localização

Configurações → Trader operation · Live → botão
**Iniciar / executar ciclo Live**.

Os controles tradicionais Start, Pause, Exit only e Stop permanecem para
parada de emergência e gerenciamento operacional independente.

## Comportamento em um clique

O clique requer **uma única confirmação informada sobre dinheiro real** e
encadeia SOMENTE endpoints existentes:

1. `GET /api/live-market/robot/status`
2. `GET /api/admin/system-settings`
3. `GET /api/live-market/execution/readiness`
4. `POST /api/live-market/robot/mode` (`active`, CAS `expected_revision`),
   **apenas** se o modo ainda não for `active`
5. `GET /api/live-market/robot/status` novamente
6. Se existir um plano com `post_close_signal_ready=true`:
   `GET /api/live-market/portfolio`, para confirmar mercado aberto
7. Só se o plano da sessão atual estiver preparado, tentar
   `POST /api/live-execution/winner/execute`.

Nenhum alvo, ativo, quantidade ou ordem é fabricado no frontend. A API
verifica sessão, posições, Winner, autorização, janela e idempotência.
Em concorrência, o servidor impede ordens duplicadas; a interface consulta
o estado e **não envia automaticamente uma segunda tentativa** quando a
primeira é incerta.

**Sem plano pronto:** o clique apenas liga o scheduler existente (se
necessário), que prepara após o fechamento e aguarda o candle diário seguro,
com um retry em falha. A UI informa que **não houve operação imediata**.
O clique não cria um endpoint de treinamento intradiário e não burla o
modelo de uma calibração pós-fechamento.

## Dependência

API **v10.8.112** deve estar implantada antes de ativar esta opção para
impedir que o scheduler tente treinar com o candle diário anterior ao
pregão fechado (buffer de dados de 20 minutos).

## Segurança, idioma e escopo

Interface PT/EN/ES; campos confidenciais e mensagens de broker não são
gravados pelo navegador. Apenas operador autenticado, com conferência
do estado e da conta. Paper e TCC não modificados.
