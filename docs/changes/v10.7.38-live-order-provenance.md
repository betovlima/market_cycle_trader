# Front v10.7.38 — auditoria e proveniência Live

O painel Live apresenta separadamente decisão Winner e origem da execução, usando códigos da API v10.8.126.

- `manual_alpaca_fills`: ordem manual comprovada por recibo MCT.
- `live_automated_verified`: ordem automática confirmada pelo ledger MCT.
- `live_broker_unclassified`: ordem na Alpaca sem origem confiavelmente comprovada.
- `live_no_orders`: decisão HOLD/CASH concluída sem ordens enviadas.
- `live_not_executed`: ainda não executada.
- `live_broker`: plano de compra/venda concluído pelo executor Live.

Justificativa Live é baseada em sinal D−1, sem referência a Paper. Chip de ordens reais habilitadas usa cor âmbar, não estado vermelho de falha. Traduções PT/EN/ES, layout comum com Trading e sem alterar ordens.
