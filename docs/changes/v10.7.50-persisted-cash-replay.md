# Front v10.7.50 | Segmentos CASH comprovados na Reprodução Anual

Na Reprodução Anual, a linha de patrimônio mostra o período do pregão em CASH com cor âmbar, sem alterar os valores de capital. A posição é retirada de `position_history` da API v10.8.133, não é adivinhada a partir das rotações. Sem posição comprovada, os segmentos são neutros; backtests legados continuam acessíveis. Um `FINAL_SELL` da liquidação final só marca a condição ao fechar o backtest, sem pintar o pregão inteiro como CASH.

O painel de auditoria lista os episódios registrados ao longo de todos os anos do backtest, sua duração, posição anterior/seguinte, motivo se persistido e evidências de rotações. O botão **Ver pregão** abre a data e o gráfico correspondente, inclusive de outro ano. Traduções PT/ES adicionadas.

A aplicação não altera modelo, estratégia, cronologia, ordens ou patrimônio. O backtest selecionado permanece somente leitura.

Verificar com API v10.8.133 e testar:
`node --test tests/annual-replay.test.mjs`
`pnpm build`

A atualização precisa de execução/validação e deploy separados. Histórico de duas sessões mencionado pelo usuário não foi lido diretamente da base operacional neste PR.
