# Front v10.7.49 | Arquivos históricos do Backtest na Reprodução Anual

Nova seção **Arquivos da execução** ao final da Reprodução Anual, visível para perfis que já possuem `annual_replay.view` ou `backtest.view`, inclusive o professor convidado.

A lista é obtida de `GET /api/analytics/backtests/{job_id}/files`, utilizando o mesmo `jobId` da animação. Downloads autenticados usam `downloadFile` (cookie da sessão) para o arquivo selecionado. A lista muda ao alternar o backtest; não usa os filtros de ano ou mês, pois os arquivos são da execução inteira.

Disponibilidades dependem dos registros reais, sem preencher lacunas. O manifesto SHA-256 e o pacote ZIP identificam a origem e as limitações: os arquivos resultam do analytics persistido e não substituem a base científica original do TCC.

Arquivos: `AnnualReplayFiles.jsx`, `AnnualReplayPage.jsx`, `annualReplay.css` e traduções PT/ES na `annualReplayTranslations.js` (EN é a chave original).

**Dependência obrigatória:** API v10.8.131, que libera explicitamente os endpoints para o `replay_guest`. A implantação precisa ser feita primeiro na API e depois no front. As operações Live/Paper, backtests, banco, estratégias, sinal e dados Alpaca não mudaram.

Validação: `pnpm test` (ou os testes definidos no `package.json`) e `pnpm build`; revisão/CI antes do merge.
