# Front v10.7.43 — ranking e justificativas no Annual Replay

## Alterações
Consome o novo `decision_scores[]` retornado pela API v10.8.128. Exibe as utilidades de até cinco ativos, score do ativo atual e do melhor candidato, gap entre utilidades, margem efetiva e motivo de manter/trocar quando gravados na sessão de decisão. Se o backtest preservou apenas 3 scores, exibe **(3/5 registrados)** e avisa que não infere 4º e 5º. Quando não há diagnóstico, exibe indisponibilidade.

## Compatibilidade
A resposta nova adiciona campos sem alterar equity, rotations, métricas ou ordenação do backtest. Front funciona com API antiga, mantendo escores indisponíveis. A interpretação usa `execution_date` do preditor com `decision_date` como referência, sem presumir previsão intradiária.

## Segurança e escopo
Somente leitura, login e `backtest.view` preservados; sem alteração Live/Trading, ordens, modelos, parâmetros ou pesquisa TCC. Testes de comportamento `node --test tests/annual-replay.test.mjs` e CI `pnpm build`.

## Dependência
API v10.8.128 para dados históricos e cinco posições disponíveis nos novos backtests; anteriores podem ter até três.
