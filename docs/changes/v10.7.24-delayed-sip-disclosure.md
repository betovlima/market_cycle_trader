# Front v10.7.24 — aviso explícito para decisão SIP atrasada

**Contexto:** `Reanalisar Winner agora` falhava para o
ticker AMS em IEX em 14/10/2026. O fallback SIP recente
era negado pela conta Alpaca sem assinatura para a janela
mais recente. A API v10.8.98 passa a tentar SIP histórico
com um horário de corte de 20 minutos antes da análise, de
modo uniforme para todos os ativos elegíveis.

**Branch:** `fix/v10.7.24-delayed-sip-approval-warning`.

**Visualização:** o monitor de operações Winner da tela
**Portfólio** identifica a etapa
`intraday_sip_delayed`. Depois de preparar um plano com
defasagem, informa a quantidade de minutos e a data/hora
local correspondente ao corte antes de qualquer confirmação.
Traduções PT/ES; mantém log, status bar e polling da
v10.7.23. Nenhum comando Alpaca novo, nenhuma operação
financeira.

**Limite conhecido:** a tela que contém os botões de
administração não foi localizada na `main` do
repositório frontend consultado, portanto não foi alterada.
Esse aviso é exibido no Portfólio; a API também disponibiliza
a defasagem no status administrativo e no plano aprovado.
Não afirmar que a barra e o aviso aparecem ao lado do botão
da tela administrativa.

**Validação:** build do frontend no GitHub Actions antes
de integrar à `main`. Implantação depende da API
v10.8.98 e do front v10.7.24 em produção.
