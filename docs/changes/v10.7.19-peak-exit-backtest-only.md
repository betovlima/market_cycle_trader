# Front v10.7.19 — Peak Exit somente no Backtest

## Decisão

Os gráficos de Peak Exit devem aparecer somente na tela **Backtest**.

A renderização adicional criada no Dashboard em v10.7.18 foi removida para evitar duplicação da mesma análise em duas áreas da aplicação.

## Comportamento final

- Backtest:
  - mantém `PeakExitAnalysis` logo abaixo de `Capital Rotations`;
  - exibe os indicadores e gráficos quando `peak_exit_analysis` contém operações válidas.

- Dashboard:
  - não renderiza `PeakExitAnalysis`;
  - permanece com os analytics históricos existentes.

## Compatibilidade

- Front: v10.7.19
- API esperada para novos diagnósticos TCC Control: v10.8.64

## Observação

A API v10.8.64 corrige a persistência dos diagnósticos Peak Exit para a Strategy #12 sem alterar o engine científico congelado do TCC v1.0.6.
