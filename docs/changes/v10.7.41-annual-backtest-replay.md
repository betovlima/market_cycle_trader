# Front v10.7.41 — Annual Backtest Replay (read-only)

## Objetivo
Nova aba de navegação **Annual Replay / Reprodução Anual**, acessível a perfis com `backtest.view`, para visualizar um ano do histórico de qualquer backtest concluído presente na lista de Analytics. Nenhuma pesquisa, retreinamento ou ordem é executada.

## Dados
- Utiliza exclusivamente os endpoints **existentes** `GET /api/analytics/backtests?limit=500` e `GET /api/analytics/backtests/{job_id}`.
- Reconstrói a sequência visual por pregão a partir de `equity[].timestamp`, `equity[].simulation_equity` e `rotations[].executed_at/from_asset/to_asset`; não atualiza MongoDB nem consulta a Alpaca.
- A posição exibida é derivada das operações efetivamente gravadas. Se não houver registros suficientes, exibe `—`.
- O capital inicial do ano é a última observação anterior, se disponível; quando ausente, a primeira observação do ano, com ressalva na tela.
- Eventos associados ao dia exibem `realized_pnl` apenas quando persistido.
- **Não inventar escores de utilidade.** O endpoint legado não expõe a classificação diária de todos os ativos; a aba sinaliza indisponibilidade. Este componente não reexecuta decisões.
- Quando backtest não possui curva de capital persistida, exibe indisponibilidade, em vez de trajetória sintética.

## Interface
Seleção de backtest e ano, avanço/retrocesso diário, slider, play/pause, 0,5× a 4×, salto para próxima rotação, visualização da posição, capital, retorno acumulado no ano e desenho progressivo da curva.

## Segurança e escopo
- Acesso a nova aba condicionado a `backtest.view`, inclusive no roteador do App. Leitura só após autenticação da API existente.
- **Operacional MCT**, nunca TCC; sem alterar serviços de corretora, Live, Trading/Paper, estratégia Winner ou `main`.
- Apenas frontend: API operacional permanece na versão instalada (verificada em `/health`).
- Lista atualmente restrita a 500 backtests concluídos (limite do endpoint atual). Paginação integral e captura de escores exigiriam evolução versionada da API, fora desta entrega.

## Testes/validação
`node --test tests/annual-replay.test.mjs`; `pnpm build` e CI do GitHub no PR.
Valida-se sincronização cronológica, manutenção entre negociações, referência ao ano anterior, ausência de dados, ausência de valores inventados e cálculo de trajetória progressiva.
