# Front v10.7.20 — Peak asset selector dark theme

## Cause

The Peak Exit asset selector matched the dark application while closed, but the native option popup used a light browser/OS palette on Windows/Chrome. The option text was therefore too light against a white background.

## Change

- Apply `color-scheme: dark` to the Peak Exit selector.
- Use a dark navy background and high-contrast text for the control and options.
- Add clearer hover and focus states.
- Use a darker selected-option background where the browser allows native option styling.

## Scope

This is a visual-only Front change. It does not change backtest data, Peak Exit calculations, API payloads, or chart behavior.

## Version

Front v10.7.20.
