# Front v10.7.20 — correção de renderização dos gráficos do Portfolio

## Causa

Os gráficos de evolução do portfólio e P/L por ativo recebiam dados válidos,
mas usavam diretamente o `ResponsiveContainer` do Recharts dentro do grid do
Portfolio. Nesse layout de produção, o container não media corretamente as
dimensões disponíveis e o SVG não era desenhado.

A evidência em tela era:
- títulos e caixas dos gráficos visíveis;
- nenhuma linha, barra, eixo ou mensagem de ausência de dados;
- ranking de candidatos carregado normalmente.

## Correção

Os dois gráficos passaram a usar o componente já existente
`AnalyticsResponsiveContainer`, que mede explicitamente largura e altura com
`ResizeObserver` e injeta essas dimensões no gráfico.

Isso evita dependência da medição automática do Recharts nesse layout.

## Impacto

Somente Frontend.

Nenhum endpoint, dado, modelo, decisão, ordem ou regra operacional foi alterado.
