# Front v10.7.17 — Peak-to-exit analytics

## Objective

Visualize the frozen API v10.8.63 peak-to-exit diagnostics without mixing every asset into one crowded chart.

## UI

The Backtest Analytics performance explorer now includes a separate **Peak proximity and exit timing** section.

It contains:

- four summary cards: median distance from peak, median peak capture, median maximum run-up and median sessions from peak to exit;
- a cross-asset bar chart for the 12 most frequently closed assets;
- an asset selector;
- a per-operation chart for the selected asset comparing exit distance with maximum run-up;
- a selected-asset scatter plot comparing peak capture with the maximum post-exit move over the next 10 complete sessions.

Backtests that predate API v10.8.63 do not fabricate the new metrics from current market history. The UI shows an availability message instead.

## Internationalization

New labels and explanations are available in PT-BR and ES through `peakExitTranslations.js`.
