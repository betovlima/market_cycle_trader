# Front v10.7.23 — barra de status e log das operações Winner

**Solicitação:** o usuário pediu barra de status e log na tela durante
**Reanalisar Winner agora** e **Executar plano atual na Alpaca**.

**Motivação:** o Portfólio v10.7.22 exibia somente a última etapa
e a mensagem de falha; não havia histórico das etapas da reanálise
nem acompanhamento visual da execução manual em Alpaca.

**Entrega:** componente `WinnerOperationMonitor` montado na tela
**Portfólio**, com cabeçalho, estado aguardando/rodando/concluído/
falha/revisão, barra de andamento com contagem real quando aplicável,
barra animada sem percentual inventado durante o treinamento ou
execução da corretora, horário da última atualização, nome da
operação e log cronológico das últimas 30 entradas (histórico
persistido de até 90 na API). Layout responsivo e textos PT/ES,
atualizados por `GET /api/paper-market/public-robot-status`
a cada 10 segundos (intervalo já introduzido na v10.7.22).

A API v10.8.97 fornece `manual_reanalysis`, `manual_execution`
e `manual_operation_log`. Não existe aqui botão para iniciar
ou enviar ordens: a tela é apenas informativa. O componente da
tela administrativa que renderiza os dois botões não foi encontrado
na branch `main` deste repositório; portanto **não afirmar** que
os botões foram alterados ou que deixam de aguardar a chamada HTTP.

**Branch:** `fix/v10.7.23-winner-operation-timeline`.
**Testes:** build do frontend no GitHub Actions.
**Risco:** nenhum comportamento de negociação/estratégia,
sem alterações de dados ou execução de ordens durante o
desenvolvimento.
