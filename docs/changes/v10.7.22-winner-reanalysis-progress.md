# Front v10.7.22 — Acompanhamento da reanálise manual da Winner

## Motivo

Em 14/10/2026, o usuário executou **Reanalisar Winner agora** e a
API retornou `CurrentSessionIntradayDataMissing` para AMS no feed IEX.
O botão de execução não ficou habilitado, corretamente, mas a tela
não indicou a etapa ou a razão da falha.

## Implementação

Na tela **Portfólio**, apresentar um aviso de estado legível do
`manual_reanalysis` enviado pelo endpoint de leitura
`GET /api/paper-market/public-robot-status`. O aviso identifica
a validação, coleta diária, coleta IEX, eventual retry SIP,
treinamento LightGBM, gravação do plano e falhas. Os contadores
mostram quantos ativos foram processados, sem percentual fictício.
Após uma reanálise aprovada, instruir o usuário a conferir o plano
no Trader antes de executar na Alpaca. Traduções PT/ES incluídas;
consulta do status a cada 10 segundos.

O aviso somente acompanha a API v10.8.96. Não envia ordens e não
muda o estado dos botões nem os parâmetros da estratégia. O código
do componente que efetivamente renderiza **Reanalisar Winner agora**
e **Executar plano atual na Alpaca** não foi identificado na
`main` do frontend consultado. Essa integração direta e um
endpoint verdadeiramente assíncrono permanecem para uma etapa
posterior, a ser baseada no código efetivamente implantado.
