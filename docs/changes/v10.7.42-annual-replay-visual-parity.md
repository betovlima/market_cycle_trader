# Front v10.7.42 — Annual Replay layout parity

## Context
A reprodução anual foi aprovada como ferramenta de visualização, mas a aba integrada em v10.7.41 não tinha as mesmas informações e a mesma hierarquia visual da simulação HTML de 2025.

## Alteração
- Layout de quatro métricas: pregões, rotações, ativos com pontuação realmente persistida (ou `—`) e retorno anual.
- Controles da animação: reproduzir/pausar, anterior/próximo pregão, rotação anterior/próxima, velocidade em pregões/s e slider.
- Painel esquerdo: ativo anterior, melhor candidato documentado / ativo comprado, posição efetiva, cinco maiores escores quando houver dados, explicação da troca.
- Painel direito: capital acumulado com curva progressiva, variação anual e atalhos por mês.
- Faixa inferior: últimas 12 operações registradas com navegação para o pregão escolhido.
- Responsivo, sem alterar identidade visual do frontend do MCT; traduções PT/ES/EN.

## Fidedignidade dos dados
A API MCT atual entrega a curva de capital e as rotações executadas, mas não as pontuações individuais de todos os ativos por pregão no contrato `GET /api/analytics/backtests/{job_id}`. O novo modelo aceita opcionalmente `decision_scores[]` anexados por `execution_date` e com `top_scores[]`, **somente quando explicitamente presentes**. Não se inventam escores, ranking, quantidade de candidatos nem motivo de `HOLD`; o campo fica indisponível para backtests sem esses registros. A maior utilidade é exibida apenas quando seu valor foi realmente fornecido; caso contrário o destaque é apenas o ativo comprado em uma operação registrada.

## Escopo / segurança
Somente frontend; acesso `backtest.view` já existente; sem API nova, alterações em MongoDB, novo backtest, consulta à Alpaca, ordens Paper/Live, deploy ou merge automático. API v10.8.127 permanece inalterada. Para paridade completa dos escores em backtests futuros, precisaremos persistir e expor esses dados por endpoint de leitura com contrato e permissões adequados.

## Verificação
`node --test tests/annual-replay.test.mjs`; `pnpm build`; CI `frontend-build`, testes novos de pontuação opcional e ausência de valores sintéticos.
