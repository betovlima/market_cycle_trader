# Frontend v1.12.76 — Portfolio workspace optimization

- Reorganizes the Portfolio tab around account evolution and the active trade.
- Replaces the six isolated account KPI cards with one compact Portfolio Summary panel.
- Unifies Alpaca Paper connectivity, robot state, market state and the live schedule in one Trading Session panel.
- Reduces the live schedule footprint while keeping Analysis, Execution, Daily close and Portfolio update countdowns visible.
- Expands Portfolio Evolution to roughly three quarters of the primary content width on desktop.
- Replaces Current Holding with a denser Current Trade panel that emphasizes asset, quantity, entry, current price, market value, unrealized P/L and return.
- Tightens Recent Paper Orders spacing so more execution history remains visible in the same viewport.
- Keeps API contracts, Paper robot behavior, strategy logic, strategy configuration and broker execution unchanged.
- Keeps protected strategy information out of the frontend.
- Updates the visible frontend version badge to `v1.12.76`.

Backend remains `v1.13.25`.
