# Front v1.12.114 — Global parameter search

- Added a two-point measurement ruler to Portfolio Evolution.
- Measure mode selects point A and point B from existing portfolio history without changing backend data.
- Displays start/end values, absolute difference, percentage change and elapsed interval.
- Draws reference lines, endpoint markers and a highlighted time band between selected points.
- Measurement mode temporarily disables chart panning to avoid click conflicts; normal zoom/pan returns after point B is selected.
- API remains v1.13.43 unchanged.
